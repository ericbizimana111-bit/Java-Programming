enum  = (short for enumeration) is a special type in Java that represents a fixed set of constants.


package enums;

public enum StudentStatus {
ACTIVE,
SUSPENDED,
GRADUATED,
EXPELLED
}
code                 Meaning
---------------------------------------------------------------------------------- |
| `public`        | Makes the enum accessible from other classes, subject to normal Java access rules. |
| `enum`          | Declares an enumeration type.                                                      |
| `StudentStatus` | The name of our enum.                                                              |
| `ACTIVE`        | One of the permitted constants.                                                    |
| `SUSPENDED`     | Another permitted constant.                                                        |
| `GRADUATED`     | Another permitted constant.                                                        |
| `EXPELLED`      | Another permitted constant.                                                        |
